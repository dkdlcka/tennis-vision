# 추가로 가능한 분석

지금 파이프라인은 공의 3D 궤적(포물선 구간), 모든 바운스·타구 시점과 위치, 포인트 결과를 이미 갖고 있습니다. 필요한 추가 작업 기준으로 나눴습니다.

## 1. 지금 데이터로 바로 가능한 것

| 분석 | 방법 | 상태 |
|---|---|---|
| 서브 속도 (평균/최고) | 서브 구간 포물선의 초기 속도 | 구현됨 |
| 샷 속도 | 타구 직후 포물선 속도 | 구현됨 |
| 네트 통과 높이 | 포물선이 y=0을 지날 때 높이 − 네트 높이 | 구현됨 (`net_clearance_m`) |
| 바운스 히트맵 / 깊이 비율 | 바운스 코트 좌표 | 구현됨 (앱 바운스 맵, `deep_pct`) |
| 라인 접전 목록 | 라인까지 거리 5cm 이내 바운스 | 구현됨 (`close_calls`) |
| 서브 코스 분포 (와이드 / 바디 / T) | 서비스 박스를 폭 방향 3등분 | 다음 작업, 쉬움 |
| 샷 방향 (크로스 / 다운더라인 / 센터) | 타점 x와 바운스 x 비교 | 다음 작업, 쉬움 |
| 타점 높이 | 타구 순간 공 높이 (`hits[].height_m`) | 값은 있음, 통계화 필요 |
| 스핀 경향 추정 | 바운스 전후 수평속도 비율과 반사각 (탑스핀은 속도가 덜 줄고 높게 튐) | 실험 필요 |
| 에러 유형 | 아웃(롱/와이드 구분) vs 네트 vs 투바운드 | 롱/와이드 구분만 추가하면 됨 |
| 압박 상황 성적 | 브레이크 포인트, 듀스, 세컨드 서브 포인트 승률 | 점수 기록으로 계산 가능 |
| 체력 추이 | 경기 후반 서브 속도·퍼스트 서브 성공률 변화 | 시간순 집계만 하면 됨 |

## 2. 선수 인식을 붙이면 가능한 것

사람 검출 + 포즈 추정 모델(예: YOLO pose, RTMPose)을 한 번 더 돌리면 됩니다.

- **선수 위치·이동 거리**: 발 위치를 코트 좌표로 옮겨 이동 거리, 코트 커버리지 히트맵, 샷 후 리커버리 위치.
- **샷 종류 분류**: 포핸드 / 백핸드 / 발리 / 스매시 / 서브. 타구 시점의 공 위치가 몸 어느 쪽인지 + 포즈.
- **스윙 폼**: 타점이 몸 앞에 있는지, 준비 동작 시작 타이밍, 스플릿 스텝 타이밍, 서브 트로피 자세와 무릎 굽힘. 같은 사람의 좋은 샷과 나쁜 샷을 나란히 비교하는 방식이 실용적입니다.
- **포인트 판정 보강**: 공이 선수 뒤로 가려졌을 때 타구 시점을 포즈로 보완해 투바운드/발리 구분 정확도를 높입니다.

## 3. 영상 편집·리포트

- **하이라이트 자동 생성**: 긴 랠리, 에이스, 접전 판정 장면을 잘라 붙이기. 기존 tennis-shorts 작업(ffmpeg 쇼츠 생성)과 연결하기 좋습니다.
- **판정 리플레이**: 바운스 순간을 확대하고 코트 선 위에 착지 지점을 그린 "호크아이" 스타일 화면.
- **경기 간 추세**: 여러 경기를 쌓아 서브 속도, 에러 비율, 샷 깊이 변화 그래프.

## 추천 순서

1. 실제 경기 영상 몇 개로 현재 판정 정확도 확인 (가장 중요)
2. 서브 코스, 샷 방향, 롱/와이드 에러 구분 (지금 데이터로 바로 가능)
3. 선수 위치 추적 (이동 거리, 커버리지)
4. 샷 종류 분류와 폼 분석
